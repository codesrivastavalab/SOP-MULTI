# Experimental Scattering Data 
The experimental scattering data used in the article were pooled from multiple published articles (cited below). <br/>
We thank all the research groups associated with these articles for making the scattering data available. 

In cases where the data was unavailable, we extracted the datapoints from the original article using the WebPlotDigitizer.

Ref: [https://automeris.io](https://automeris.io) <br/>
Rohatgi, Ankit. "WebPlotDigitizer https://automeris.io." WebPlotDigitizer2018 (2017).

## TDP-43 (W2A, all tryptophan residues mutated to alanine)
The data points were extracted from the scattering curve reported in the following article
Wright, Gareth SA, et al. "Purification and structural characterization of aggregation-prone human TDP-43 involved in neurodegenerative diseases." Iscience 23.6 (2020). <br/>
Ref: [ https://doi.org/10.1016/j.isci.2020.101159](https://doi.org/10.1016/j.isci.2020.101159) <br/>
